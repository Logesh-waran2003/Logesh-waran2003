## 🔨 What I'm building

### 💓 [Pulse](https://github.com/Logesh-waran2003/pulse) — Terminal companion for Claude Code
Lives in your Claude Code status bar. Watches all your sessions, tells you to drink water, celebrates when your agent finishes. Built with Python + Claude Code hooks.
```bash
npx pulse-dev install
```

### 🤖 [Agent Hub](https://github.com/Logesh-waran2003/agent-hub) — Multi-agent workspace
Web UI for running multiple AI coding agents in parallel — live terminals, @mention context injection, real-time Kanban board. Built with Node.js + WebSockets.

### 🐍 [memtop](https://github.com/Logesh-waran2003/memtop) — Hierarchical RAM monitor
Per-app, per-Chrome-tab, per-tmux-pane memory tracking. Live TUI + snapshot mode. Built with Python.

### 🧩 [manga-reader-extension](https://github.com/Logesh-waran2003/manga-reader-extension) — Chrome extension
Auto-scrolling, speed control, chapter navigation for manga reading. Built with JavaScript.
